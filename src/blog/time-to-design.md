This week marked the beginnings of my design phase, commencing with Logical Design. I started with drawing up some ERD’s to get a good idea on what the flow of data would need to be for the system.

I went into SABIC this week to speak to Tony Porritt – Applications Manager. I wanted to conduct a little more research on how the system would be used, and find out a little more on the hardware. Tony was also a great help with providing some more information on Android development. Although I have previously used Java at Uni, I had no idea how the Android SDK worked; so I have a little more insight on where to start, and know a little about Android quirks.
